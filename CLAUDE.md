Use Cursor AI to help write, explain, and review code.

## Project Guidelines

- Build clean, readable, and modular React code.
- Prefer reusable components over duplicated code.
- Keep validation logic separate from UI components when appropriate.
- Follow modern React best practices.
- Avoid unnecessary complexity.

## Prompting Lessons Learned

From this assignment, I learned:

- Be specific about functional requirements instead of giving vague instructions.
- Explicitly mention validation rules, accessibility, and user experience requirements.
- Describe the desired visual style if UI quality is important.
- Break complex tasks into smaller, clear requirements.
- Ask the AI to review and improve its own output before considering the task complete.
- A detailed prompt produces more polished, user-friendly, and maintainable code than a vague prompt.

## Coding Preferences

- Use meaningful variable and function names.
- Keep components focused on a single responsibility.
- Add comments only where the logic is not immediately obvious.
- Keep the UI clean, responsive, and accessible.
